# 清晰模块

用明确的几何轮廓表达秩序，把复杂操作收进一个紧凑而亲切的形体。形体需要经过细致推敲，使它在十六像素的空间内仍有完整的辨识度；每一处留白都服务于识别。

以靛蓝建立稳定的视觉重心，以青色给出少量行动感。高对比的白色主体让形体脱离背景，色彩的运用保持克制。精心校准色块的面积关系，让明亮的点缀成为锚点。

圆角带来轻松感，正交结构保持精确。粗细、间距与重心通过反复审视协调，细节不能依赖放大才能被看见。优秀的工艺体现在删去冗余之后仍然清晰的轮廓。

大面积留白建立节奏，文字只承担命名与定位。展示时将大图形与实际小尺寸并置，让每一款的轮廓、比例与识别性接受同样的检验。

## 方案与接入

- **Toolbox / 工具箱（默认）**：白色工具箱与青色锁扣，直观表达在线工具集合。
- **Focus frame / 裁剪框**：裁剪定位角与像素，突出图片处理场景。
- **Modular T / 模块 T**：模块组成 T 字母，表达工具聚合。

矢量源文件与 512px PNG 位于 `products/tools/shared/images/brand/`；`logo.svg` 为当前导航标识。运行 `python scripts/generate-tools-brand.py` 可重建所有图标和对比稿，需要 Pillow。预览字体使用 Windows Segoe UI，站点图标不依赖字体。

所有入口静态声明 ICO、96px PNG 与 Apple touch icon，便于爬虫直接发现；导航栏使用同款 SVG。保留既有的 favicon 和 PNG URL，新增 96px PNG 用于高分辨率搜索展示。搜索引擎更新需要重新抓取，显示与否由搜索引擎决定。
